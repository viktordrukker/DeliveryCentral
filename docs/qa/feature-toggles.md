## Summary
- **90** flags total — **19** default-ON, **71** default-OFF.
- **Staging effective state:** v2-staging sets backend `FORCE_ALL_FLAGS_ON=true` (`docker-compose.v2-staging.yml:38`), which short-circuits `PlatformFlagsService.isEnabledByKey → true` (`platform-flags.service.ts:977`) — so **every backend-gated flag is ON on staging regardless of default**. The FE bundle additionally force-sets only **`dsRefresh`** and **`workspaceMe`** ON; all other FE-only gates use their static default on staging (they are NOT forced).
- **Half-built-but-hidden (criterion "features not built end-to-end are HIDDEN"):** 3 flags hide scaffolded/never-consumed features and are correctly default-OFF → `customFields`, `entityLayouts`, `workflowDefinitions`. Discipline holding (these are NOT bugs — they confirm half-built surfaces stay hidden).
